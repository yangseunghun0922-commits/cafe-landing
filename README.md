# cafe-landing ☕

카페를 소개하는 **간단한 랜딩 페이지**(소개용 한 장짜리 웹페이지)입니다.
HTML과 CSS만으로 만들어서 별도 설치 없이 바로 볼 수 있어요.

## 폴더 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지의 내용(메뉴, 소개, 오시는 길 등)을 담은 파일 |
| `style.css` | 색상, 배치 등 디자인을 담은 파일 |
| `README.md` | 이 폴더를 설명하는 문서 |

## 페이지 구성

- 상단 메뉴: 메뉴 / 소개 / 오시는 길로 이동
- 히어로 영역: 카페를 소개하는 첫 화면 문구와 버튼
- 대표 메뉴: 아메리카노, 카페라떼, 수제 치즈케이크 카드
- 카페 소개, 오시는 길(주소·영업시간·전화번호)

## 실행 방법

1. 이 레포를 내려받습니다. (`git clone`: 레포를 내 컴퓨터로 복사하는 명령)
2. `index.html`을 더블클릭해 브라우저로 엽니다.

## 참고

- 메뉴 가격, 주소, 전화번호는 **예시 값**이므로 실제 정보로 바꿔서 사용하세요.
- 모바일 화면에서도 보기 좋게 반응형(화면 크기에 맞춰 배치가 바뀌는 방식)으로 만들었습니다.
